# LOGISTICS FIX4 REAL AUDIT

Реальная причина: предыдущий модуль был привязан только к добавленным позициям корзины. Если пользователь смотрел расчет до добавления в корзину, блок оставался скрытым. Также добавлена прямая синхронизация события cartRender.

Исправления:
- логистика показывается по корзине;
- если корзина пустая — показывается по текущей рассчитанной позиции;
- cartRender отправляет событие paver:cart-updated;
- добавлен read-only экспорт window.__pcCartSnapshotCurrent;
- блок вставляется перед итогом корзины;
- внешний logistics_rules.json остается override, встроенные правила — fallback;
- диагностика: window.PaverLogistics.diagnose().

Цены, скидки, расчет поддонов и Tilda submit не изменялись.
