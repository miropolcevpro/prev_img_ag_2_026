# Admin upload staging

Сюда загружаются файлы, скачанные из закрытой Tilda-админки:

- `price_catalog.generated.json`
- `admin_settings.generated.json`
- `logistics_rules.generated.json`
- `price_validation_report.json`

После загрузки запустите GitHub Actions → `Publish prices from admin upload` → `Run workflow`.
